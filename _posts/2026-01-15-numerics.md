# 误差分析
误差分类：模型误差、观测误差、截断误差（方法误差）、舍入误差（计算机表示精度不足）

误差的定义：给定一个量的真实值$x$，对近似值$x^\*$ ，定义：
- （绝对）误差$e^\* = x - x^\*$
- 误差限：$\epsilon^\* = sup\{\|e^\*\|\}$
- 相对误差：$e_r^\* = \frac{e^\*}{x} \approx \frac{e^\*}{x^\*}$
- 相对误差限：$\epsilon_r^\* = \frac{\epsilon^\*}{\|x\|} = sup\{\|e_r^\*\|\}$

若近似值$x^\*$的误差限是某一位的半个单位，该位到$x^\*$的第一位非零数字有n位，就说$x^\*$有n位有效数字。因此$x^\* = \pm 10^m \times \overline{a_0 a_1 \cdots a_{n-1}} \times 10^{-(n-1)}$，且误差限满足$\epsilon^\* \le 10^{m-n+1} * \frac{1}{2}$。

相应的相对误差限$\epsilon_r^\* \le 10^{-(n-1)} * \frac{1}{2a_0}$
- 证明思路：只要对$x^\*$放缩至高位即可

误差限的运算规则：
- $\epsilon(x_1^\* - x_2^\*) \le \epsilon(x_1^\*) + \epsilon(x_2^\*)$
- $\epsilon(x_1^\* \times x_2^\*) \le \epsilon(x_1^\*) \times \|x_2^\*\| + \epsilon(x_2^\*) \times \|x_1^\*\|$
- $\epsilon(\frac{x_1^\*}{x_2^\*}) \le \frac{\epsilon(x_1^\*) \times \|x_2^\*\| + \epsilon(x_2^\*) \times \|x_1^\*\|}{\|x_2^\*\|^2}$
- 对可微函数$f(x)$，$\epsilon(f(x^\*)) \le \epsilon(x^\*) \times \|f^\prime(x^\*)\|$
  - 可以使用泰勒展开证明

算法的数值稳定性：输入有误差，但计算过程中舍入误差不增长。

条件数$C_p = \frac{\epsilon(f(x^\*))}{\epsilon(x^\*)}$。

数值问题的病态性：输入数据的微小误差引起计算结果的巨大误差。
- 条件数较大则病态。

避免误差的方法：
- 注意数值稳定性
- 避免相近数的相减（丢失有效位数）
- 避免量级差距大的数加减、除以近似0的数、乘以过大的数（被舍入）
- 采取简化计算方法

# 插值
## 插值问题
设函数$f(x)$在$[a, b]$上有定义，给定$a \le x_0 < x_1 < \cdots < x_n \le b$，若存在$F(x)$满足$F(x_i) = f(x_i), i = 0, 1, \cdots, n$，则称$F(x)$为插值函数，$x_i$为插值节点。

## 多项式插值
使用待定系数法，设不超过n次的多项式$F(x) = \sum_{i = 0}^n c_ix^i$，则有：

$$\sum_{j = 0}^n c_j x_i^j = f(x_i), i = 0, 1, \cdots, n$$

即关于$c_i$构成了n+1元线性方程组。系数矩阵为范德蒙德矩阵，行列式不为0，存在唯一解。

截断误差：引入$\omega_{n+1}(x) = \prod_i(x - x_i)$，$R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}\omega_{n+1}(x)$
- 设$f(x)$n+1阶可导，余项$f(x) - F(x)$形式为$R_n(x) = K(x)\omega_{n+1}(x)$，则对任意$x \ne x_i$处设函数$G(t) = f(t) - F(t) - K(x)\omega_{n+1}(x)$，有n+2个零点，由罗尔中值定理得到$G^{(n+1)}(t)$至少有一个零点$\xi$，满足$f^{(n+1)}(\xi) = K(x)(n+1)!$。

### 拉格朗日插值
取插值基函数$L_j(x) = \prod_{i = 0, i \ne j}^n \frac{x - x_i}{x_j - x_i}$。

插值函数$F(x) = \sum_{j = 0}^n c_j L_j(x)$。

### 牛顿插值
定义差商$f\[x_0, x_1\] = \frac{f(x_1) - f(x_0)}{x_1 - x_0}$，$f\[x_0, x_1, \cdots, x_n\] = \frac{f\[x_0, x_1,\cdots x_{n-2}, x_n\] - f\[x_0, x_1,\cdots x_{n-2}, x_{n-1}\]}{x_n - x_{n-1}}$。
- 可表示为函数值的线性组合
- 差商与节点的排列顺序无关
- 若$f(x)$n次可导，则$f\[x_0, x_1, \cdots, x_n\] = \frac{f^{(n)}(\xi)}{n!}$
- 与（向前）差分的关系：$f\[x_k, x_{k+1}, \cdots, x_{k+m}\] = \frac{1}{m!}\frac{1}{h^m}\Delta^m f_k$，其中$x_{k+i} = x_k + ih, i = 1, 2, \cdots, m$

插值函数$F(x) = f(x_0) + \sum_{j = 1}^n f[x_0, x_1, \cdots, x_j] \prod_{i = 0}^{j - 1} (x - x_i)$。
- 强化的余项形式：$R_n(x) = f\[x, x_0, x_1, \cdots, x_n\]\omega_{n+1}(x)$

## 埃尔米特插值
额外要求在特定点上的导数值相同。

一般有n+1个条件，插值函数的次数不超过n。

余项形式为$R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}\omega_{n+1}(x)$，即将导数相同节点看作重节点。

### 泰勒插值
在一点$x_0$上的n阶导数值均相等。

由泰勒展开，$F(x) = f(x_0) + \sum_i^n \frac{f^{(n)}(x-x_0)^i}{i!}$

余项：$R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x - x_0)^{n+1}$

### 待定系数法求三点插值
设$x_0, x_1, x_2$的函数值相等，且x_0处的导数值相等。

则可设$F(x) = F_{Newton}(x) + A(x - x_0)(x-x_1)(x-x_2)$，由导数值相等得到A。

### 基函数法求两点三次插值
设两点$x_0, x_1$的函数值相等，且导数值相等。

则可设$F(x) = F_1(x)f(x_0) + F_2(x)f(x_1) + F_3(x)f^\prime(x_0) + F_4(x)f^\prime(x_1)$，满足：

||$F_1(x)$|$F_2(x)$|$F_3(x)$|$F_4(x)$|
|$F(x_0)$|1|0|0|0|
|$F(x_1)$|0|1|0|0|
|$F^\prime(x_0)$|0|0|1|0|
|$F^\prime(x_1)$|0|0|0|1|

且四个函数类似于拉格朗日插值基函数。

## 分段低次插值
在每个区间内进行插值

### 分段线性插值
在每个区间内进行线性插值

### 分段三次埃尔米特插值
在每个区间内进行三次埃尔米特插值

### 三次样条插值
要求插值点上二阶导数连续。

且需附加边界条件：
- 两端的一阶导数值
- 两端的二阶导数值
  - 自然边界条件：两端的二阶导数值均为0
- 周期函数：两端的导数值、二阶导数值相等

## 切比雪夫插值
用切比雪夫多项式的零点作为插值节点，能够保证最大误差最小。

# 函数逼近
## 理论
基于泛函分析理论。

定义权函数：$非负\rho(x) \in C[a,b], \forall k \ge 0, \int_a^b x^k \rho(x)dx 存在且有限, 且\forall 非负f \in C[a,b], \int_a^b f(x) \rho(x)dx = 0 \Rightarrow f(x) = 0$。

带权内积：$<f(x), g(x)> = \int_a^b f(x)g(x)\rho(x)dx$

最佳函数逼近：若由函数构成的线性空间$\Phi$中，有$\forall f(x) \in C[a, b], 使得\|\|f(x) - P(x)\|\|最小的P(x) \in \Phi$, 则称$P(x)$为最佳逼近函数。
- 若$\Phi$为多项式空间，则称为最佳逼近多项式。

正交多项式（簇）：多项式构成的正交函数簇：
- 施密特正交化
- 递推式：$P_0(x) = 1, P_{-1}(x) = 0, P_{n+1}(x) = (x - \frac{<xP_n(x), P_n(x)>}{<P_n(x), P_n(x)>})P_n(x) - \frac{<P_n(x), P_n(x)>}{<P_{n-1}(x), P_{n-1}(x)>}P_{n-1}(x)$
- 在区间内有n个不同的零点

特殊情况下，将相应的首1多项式记号上方加波浪号：
- 勒让德多项式：区间$[-1,1]$上，取权函数$\rho(x) = 1$，$P_n(x) = \frac{1}{2^nn!} \frac{d^n}{dx^n}(x^2 - 1)^n$。
- 切比雪夫多项式：区间$[-1,1]$上，取权函数$\rho(x) = \frac{1}{\sqrt{1 - x^2}}$，$T_n(x) = cos(n \arccos x)$
- 第二类切比雪夫多项式：区间$[-1,1]$上，取权函数$\rho(x) = \sqrt{1 - x^2}$，$U_n(x) = \frac{sin((n+1) \arccos x)}{\sqrt{1 - x^2}}$
- 拉盖尔多项式：区间$[0,+\infty)$上，取权函数$\rho(x) = e^{-x}$，$L_n(x) = e^x\frac{d^n}{dx^n}(x^ne^{-x})$
- 埃尔米特多项式：区间$(-\infty,+\infty)$上，取权函数$\rho(x) = e^{-x^2}$，$E_n(x) = (-1)^ne^{x^2}\frac{d^n}{dx^n}(e^{-x^2})$

## 最佳一致逼近
范数取无穷范数，此时$min\|\|f(x) - P(x)\|\| = \widetilde{T}_n(x)$

## 最佳平方逼近
范数取平方范数。
